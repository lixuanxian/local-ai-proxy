# CLAUDE.md

## Project Overview

Local AI Proxy is a unified API gateway that routes chat requests to multiple AI providers through both OpenAI-compatible and Anthropic-compatible endpoints. It includes a React web dashboard for management, SQLite persistence, and Docker sandbox support.

**Port:** 3199 (configurable via `PORT` env var)

## Repository Structure

  utils.js             # Shared utilities

  openai-compat.js     # OpenAI-compatible API adapter
  ollama.js            # Ollama API adapter

  copilot-cli.js       # GitHub Copilot CLI adapter
  docker-sandbox.js    # Docker sandbox provider
api/
  openai/router.js     # /v1/chat/completions, /v1/models
  anthropic/router.js  # /v1/messages
  management/router.js # /api/* CRUD endpoints

  src/
    App.jsx            # Root component with sidebar navigation
    api.js             # Fetch wrapper for backend

## Architecture

### Provider System

Providers follow an adapter pattern with two base classes:
- **`BaseCLIProvider`** — spawns local CLI processes (`child_process`), buffers stdout
- **`BaseAPIProvider`** — makes HTTP requests, supports SSE streaming

Each provider defines:
- `modelPatterns` — regex array for auto-routing by model name
- `buildArgs()` / request construction
- Response/stream parsing

### Request Flow

1. Request arrives at `/v1/chat/completions` (OpenAI) or `/v1/messages` (Anthropic)
2. Messages array validated
3. Provider resolved: explicit `provider` param → model name pattern match → default
4. Provider's `chat()` or `chatStream()` called
5. Response formatted to match the request's API format
6. Logged to SQLite if logging enabled

### Database (SQLite with WAL mode)

Tables: `providers`, `settings`, `request_logs`, `apps`, `docker_configs`

Migrations run automatically on startup in `lib/db.js`.

### Environment Variables

| Variable | Default | Purpose |
|---|---|---|
| `PORT` | 3199 | Server port |
| `DEFAULT_PROVIDER` | "claude" | Initial default provider |
| `OLLAMA_HOST` | http://localhost:11434 | Ollama endpoint |
| `OPENAI_BASE_URL` | http://localhost:1234 | OpenAI-compat endpoint |
| `OPENAI_API_KEY` | (empty) | API key for OpenAI-compat |

## Key Conventions

- **No test framework** — the project has no unit/integration tests
- **Backend:** Plain Node.js + Express, no TypeScript, no transpilation
- **Frontend:** React 19 + Ant Design 6, Vite 7, ESLint 9
- **Database:** Synchronous `better-sqlite3` — no async/await needed for DB calls
- **Streaming:** SSE format, chunked via `res.write()` with `text/event-stream` content type
- **API keys** are masked (`***`) in management API responses
- **Request logging** truncates bodies to 10KB
- **Docker sandboxes** support both one-off (`docker run --rm`) and persistent (`docker exec`) modes
- **Frontend builds** output to `public/` which is served as static files by Express
- **No TypeScript, no Prettier** — raw JS with ESLint for the frontend only
